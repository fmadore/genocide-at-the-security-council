# Stoplist for the lexicometry in scripts/05_lexical.py.
#
# FUNCTION WORDS ONLY. This is a deliberate boundary, not an oversight.
#
# The temptation with a corpus like this is to add the genre's furniture —
# "council", "security", "resolution", "delegation", "president", "thank" — on
# the grounds that they are everywhere and say nothing. They are not, and they
# do. Whether "council" is disproportionately close to "genocide" is exactly the
# sort of thing the collocate analysis exists to find out, and a stoplist that
# removed it would be answering the question by assumption.
#
# So: determiners, pronouns, prepositions, conjunctions, auxiliaries, and the
# handful of contraction fragments the tokeniser leaves behind. Nothing else.
#
# Terms are lower-cased and compared exactly. One per line; blank lines and
# lines beginning with # are ignored.
